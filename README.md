Investment Portfolio Management System
1. Abstract

The Investment Portfolio Management System is a simple C-based console application that helps users store, track, and manage their financial investments. It allows users to add new investments, view their complete portfolio, calculate total portfolio value, and search for specific assets. This project demonstrates the use of structures, arrays, functions, and menu-driven programming in C.

2. Features of the Program

Add Investment
Users can enter asset name, buy price, and quantity.

Display Portfolio
Shows all stored investments with calculated individual values.

Total Portfolio Value
Computes and displays the total worth of all investments.

Search Investment
Finds a particular investment by its name.

Menu-Driven Interface
Simple and user-friendly interaction.

3. Technical Requirements
Software Requirements

C Compiler (GCC, Turbo C, Clang, or CodeBlocks)

Operating System: Windows / Linux

Hardware Requirements

Minimum 2GB RAM

Any basic processor

10MB storage

Programming Concepts Used

Structures

Arrays

Functions

Switch-case

Looping and conditional statements

4. Functional Requirements

The system must allow users to add up to 50 investments.

The system must store details:

Investment name

Buy price

Quantity

The system must calculate and display the total portfolio value.

The system must allow searching by name.

The system must prevent overflow when storage limit is reached.

5. How to Run the C Program
Using GCC

Save the code as portfolio.c

Open terminal or command prompt.

Run:

gcc portfolio.c -o portfolio


Then run the program:

./portfolio

Using CodeBlocks / Turbo C

Create a new project

Paste the C code

Press Compile & Run
